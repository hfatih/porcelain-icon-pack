## 🌟 Öne Çıkan Özellikler

- **480 Adet Retina 144×144 Karo:** Elgato Stream Deck ızgara standardında, 2× süper-örneklemeli pürüzsüz kenar yumuşatma.
- **İki İmza Sırlı Kaplama:**
  1. **Klasik Kemik Çini (240 İkon):** Sıcak fildişi porselen zemin, derin kobalt mavisi köşe süslemeleri ve 3D kabartmalı kobalt seramik glifi.
  2. **Kraliyet Kobaltı / Ters Zemin (240 İkon):** Derin zengin kobalt mavisi sırlı karo, beyaz mine köşe süslemesi ve 3D kabartmalı seramik rölyef.
- **Aktif/Pasif Durum Göstergesi:** İki kaplamayı eşleştirerek Stream Deck üzerinde canlı durum takibi yapabilirsiniz (Örn: Mikrofon açıkken Klasik Porselen, sessizdeyken Kraliyet Kobaltı).
- **Zod Standartlarında `.evoxpack`:** Tek tıkla evoX ve Stream Deck sistemlerine anında entegre olur.
- **Canlı İnteraktif Simülatör:** Web tarayıcınızdan 15 tuşlu simülatörü anında test edin: [https://hfatih.github.io/porcelain-icon-pack/](https://hfatih.github.io/porcelain-icon-pack/)

## 🚀 Hızlı Kurulum

### Yöntem 1: Tek Tıkla Kurulum (.evoxpack)
1. [Son Sürüm](https://github.com/Hfatih/porcelain-icon-pack/releases/latest) sayfasından **`Porcelain Icons.evoxpack`** dosyasını indirin.
2. Çift tıklayarak veya **evoX** uygulaması içerisinden açın.
3. Tüm 480 ikon kategorileriyle birlikte otomatik olarak yüklenecektir.

### Yöntem 2: Doğrudan PNG Kullanımı
1. Depoyu klonlayın veya zip olarak indirin.
2. **Elgato Stream Deck** uygulamasını açın.
3. `icons/` klasöründeki herhangi bir `.png` dosyasını istediğiniz tuşun üzerine sürükleyip bırakın.
