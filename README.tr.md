## 🚀 Hızlı Kurulum

### Yöntem 1: Tek Tıkla Kurulum (.evoxpack)
1. [Son Sürüm](https://github.com/Hfatih/porcelain-icon-pack/releases/latest) sayfasından **`Porcelain Icons.evoxpack`** dosyasını indirin.
2. Çift tıklayarak veya **evoX** uygulaması içerisinden açın.
3. Tüm 480 ikon kategorileriyle birlikte otomatik olarak yüklenecektir.

### Yöntem 2: Doğrudan PNG Kullanımı
1. Depoyu klonlayın veya zip olarak indirin.
2. **Elgato Stream Deck** uygulamasını açın.
3. `icons/` klasöründeki herhangi bir `.png` dosyasını istediğiniz tuşun üzerine sürükleyip bırakın.
